PoEPart1 — Programming 1A PoE Part 1:

Chat application — Part 1: Registration and Login feature.

 Project Overview:

A console-based Java application that allows users to:
- Register with a username, password, and South African cell phone number
- Validate input using custom checks and regex
- Log in with their registered credentials

 Classes:

- Registration — validation logic and user registration
- Login — login verification and status messages
- PoePart1 — main class (console menu)

 References:

Goyvaerts, J. 2023. *Regular Expressions: The Complete Tutorial*. [Online].
Available at: https://www.regular-expressions.info/ [Accessed: 16 September 2026].

The regular expression used for cell phone number validation in `Registration.java`
was learnt from the source above.
